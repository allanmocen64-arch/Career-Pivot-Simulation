# Career Pivot Simulator

An interactive web application designed to simulate and navigate career transitions, helping users visualize new professional pathways.

##  Features
* **Interactive Scenarios:** Simulate different career choice paths.
* **Responsive Layout:** Optimized for both desktop and mobile viewing.
* **Dynamic UI:** Smooth transitions and modern styling.

##  Tech Stack
* **HTML5:** Semantic structure.
* **CSS3:** Custom layouts and responsive design.
* **JavaScript:** Interactive simulation logic.
